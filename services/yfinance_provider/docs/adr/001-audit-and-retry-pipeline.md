# ADR 001: 株価データ欠落の自動検知とリトライパイプラインの導入

## ステータス
承認済み

## 文脈 (Context)
現在、`yfinance.duckdb`において、財務データ（`financials`, `balance_sheet` 等）は正常に収集されているものの、`prices` テーブルの日次株価データが欠落している銘柄が多数存在する。現行の `SyncEngine` は、価格バリデーションに失敗した銘柄をスキップするだけであり、再試行の仕組みが存在しないため、データが長期間欠落した状態が放置されていた。

## 決定 (Decision)
1. **監査パイプラインの導入**: 財務データは存在するが価格データが欠落（または異常に少ない）銘柄を特定する SQL クエリを作成する。
2. **リトライパイプラインの構築**: 上記クエリで抽出した銘柄を対象に、`SyncEngine.run_sync(tickers=list, force=True)` を実行する独立したプロセス（`scripts/audit_and_retry.py`）を構築する。
3. **継続的品質監視**: このリトライパイプラインを定期的に実行することで、データの完全性を担保する。

## 結果 (Consequences)
- **利点**: データ欠落を自動的に検知・修正できるため、バックテストの universe の精度が向上する。
- **欠点**: 監視プロセスが追加されるため、パイプラインの複雑性がわずかに上昇する。
- **リスク**: APIレート制限を考慮しない場合、リトライが短期間に集中して Yahoo Finance から IP ブロックを受ける可能性がある。これを防ぐために、リトライも `SyncEngine` のレート制限ロジックを遵守する必要がある。
