# Macro Economic Service: Requirement Specification

## 1. Vision & Mission
本プロジェクトの目的は、マクロ経済指標(Economic Indicators)および金利(Interest Rates)などのファンダメンタルズデータを体系的に管理する、高機能非同期型データベースを構築することである。
市場の変動を引き起こす「原因(マクロの力学)」を数値化し、長期的なトレンド分析とイベント駆動型のインパクト分析の基盤を提供することを使命とする。

## 2. Strategic Rationale: なぜこれを実装するのか
### 2.1 因果関係の可視化
市場は経済のファンダメンタルズに反応する。CPI(物価)、雇用統計、政策金利といった「原因」をデータとして保持することで、株価変動の背景にある論理的な因果関係を解明可能にする。

### 2.2 経済イベントのインパクト管理
経済指標は発表の瞬間に市場を動かす。本システムでは、単なる時系列データとしてだけでなく、「発表日」と「その時の数値(予想 vs 実績)」を管理することで、イベント時の市場の反応を分析する土台を作る。

## 3. Scope Definition
### 3.1 実装する機能 (In Scope)
- **マクロ指標の時系列管理**: CPI, 失業率, GDP, 製造業景況感指数 等を FRED や Stooq から取得。
- **金利・イールドカーブ**: 米10年債、2年債、およびそのスプレッド(逆イールド等)の追跡。
- **発表履歴の管理**: 「実績値」だけでなく、発表時の「予想値(Consensus)」および「前回値の修正」を履歴として保持する(Point-in-Time Aware)。
- **非定期的データの正規化**: 月次、四半期、年次といった異なる周期のデータを、日付ベースのクエリで横断的に抽出可能にする。

### 3.2 実装しない機能 (Out Scope)
- **株価・指数データ**: OHLC 形式の価格データは `index` サービスへ分離し、本システムでは扱わない。
- **経済予測の生成**: 本システムは「公表された統計値」のアーカイブであり、独自の経済予測アルゴリズムは実装しない。

## 4. Core Principles
1. **履歴の不変性と修正対応**: 経済指標は後日「改定(Revision)」されることが多い。本システムは改定の履歴を追跡し、分析時に「当時の数値」と「最新の修正値」を区別できるように設計する。
2. **メタデータの充実**: 指標の定義、単位(%、数百万ドル等)、ソース(FRED ID等)を厳格に定義し、データの解釈ミスを防ぐ。
3. **拡張性**: 新しい統計指標(例:特定の業界統計)が必要になった際、データエンジンのロジックを変更することなく追加できるプラグイン形式を採用する。
