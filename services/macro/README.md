# Macro Economic Database

マクロ経済指標(CPI, 政策金利, 雇用統計等)に特化した、高機能非同期型データベース・APIサーバー。

## 概要
本プロジェクトは、主要な経済指標を正規化された形式で蓄積し、分析に最適な API を提供します。
実績値だけでなく、コンセンサス予想値や前回値修正の履歴管理を特徴とします。

詳細は [Requirement Specification](docs/requirements.md) を参照してください。

## セットアップ
本プロジェクトは `uv` を使用して管理されています。

```bash
# 仮想環境の作成とインストール
uv pip install -e .
```
