# Market Index Service: Requirement Specification

## 1. Vision & Mission
本プロジェクトの目的は、グローバルな主要株価指数(Market Index)に特化した、高精度かつ高速な日足データベースを構築することである。
市場全体のモメンタムとボラティリティを定量化し、個別銘柄分析の「基準(ベンチマーク)」を提供することを使命とする。

## 2. Strategic Rationale: なぜこれを実装するのか
### 2.1 ベータ(市場収益)の分離
投資パフォーマンスを評価する際、市場全体の上げ(ベータ)によるものか、自身の選択(アルファ)によるものかを判別するためには、信頼できる指数データが不可欠である。

### 2.2 相対強度の分析
「市場平均に対してどの程度強いか」という相対強度(Relative Strength)の計算基盤として、クレンジング済みの指数データを提供する。

## 3. Scope Definition
### 3.1 実装する機能 (In Scope)
- **主要指数の正規化データ**: S&P 500, Dow Jones, Nasdaq, Nikkei 225 等の OHLCV データを DuckDB に蓄積。
- **マルチソース・フェッチ**: yfinance をメインとしつつ、欠損時は Stooq 等から補完する。
- **パフォーマンス統計**: 指数ごとの騰落率、ボラティリティ、ドローダウン等の基本統計量の提供。

### 3.2 実装しない機能 (Out Scope)
- **マクロ経済指標**: 金利、CPI 等の非価格データは `macro` サービスへ分離し、本システムでは扱わない。
- **リアルタイム・データ**: 「日足」の精度と整合性に特化し、分足・秒足は扱わない。

## 4. Core Principles
1. **データ整合性**: 指数データは分割修正等が少ないが、Ticker の変更や算出方法の変更に耐えうる柔軟なカタログ管理を行う。
2. **高速クエリ**: フロントエンドのダッシュボードで複数の指数を即座に比較できるよう、Parquet フォーマットでの最適化を行う。
