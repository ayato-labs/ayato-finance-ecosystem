# Index & Macro Database

株価指数およびマクロ経済指標に特化した高精度日足データベース・APIサーバー。

## 概要
本プロジェクトは、主要な市場指標（S&P 500, 日経225等）とマクロ経済指標（金利, CPI等）を正規化された形式で蓄積し、分析に最適な API を提供します。

詳細は [Requirement Specification](docs/requirements.md) を参照してください。

## セットアップ
本プロジェクトは `uv` を使用して管理されています。

```bash
# 仮想環境の作成とインストール
uv pip install -e .
```
