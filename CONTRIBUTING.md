# Contributing to Ayato Finance Ecosystem

First of all, thank you for considering contributing to this project! To maintain the project's sustainability and support its dual-licensing model, we require all contributors to agree to our CLA.

## 🛡️ The CLA Process (Mandatory)

To ensure we have the legal right to maintain the open-source version while offering commercial support, you must provide a **proof of agreement** to the [CLA.md](./CLA.md).

### How to agree:
1. **Pull Request (Preferred)**: In your Pull Request description, you **must** include the following sentence:
   > "I agree to the CLA of Ayato Finance Ecosystem as defined in CLA.md."
2. **Issue Comment**: If you are contributing via discussion or code snippets in an Issue, reply to the issue with the same agreement sentence.
3. **Email**: If you prefer, you can send an email to the Project Owner (see README for contact) stating your agreement along with your GitHub username.

**⚠️ Important: We cannot merge any Pull Requests without this explicit record of agreement.**

## 🚦 Contribution Policy (SV-COS)

To protect the project's commercial viability while welcoming community improvements, we categorize contributions as follows:

| Category | Examples | Action |
|---|---|---|
| **Accepted** | Bug fixes, documentation improvements, test cases. | Merged after CLA confirmation. |
| **Discuss First** | New features, major refactors, UI/UX changes. | Open an Issue for discussion before coding. |
| **Rejected** | Changes to core commercial logic, license changes. | Politely declined to protect the vendor model. |

## 💻 Development Workflow

1. Fork the repository.
2. Create a feature branch (`feat/your-feature`).
3. Ensure your code follows the existing style and includes unit tests.
4. Submit a Pull Request to the `develop` branch.
5. Include the CLA agreement statement in the PR body.

## 📝 Commit Messages
Please use the following format:
- `Feat:` New feature
- `Fix:` Bug fix
- `Docs:` Documentation changes
- `Refactor:` Code refactoring
- `Chore:` Maintenance tasks
