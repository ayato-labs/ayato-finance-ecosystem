# Contributing

Thank you for your interest! As this is primarily a personal project, please follow these simple steps for contributions:

1. **Check Issues**: See if there's an existing issue or open a new one to discuss your idea.
2. **CLA Agreement**: By submitting a PR, you agree to our [CLA](CLA.md). Please check the box in the PR template.
3. **Loguru**: Please use `loguru` for all logging to keep the codebase consistent.
4. **Tests**: Ensure any new logic is covered by simple tests.

Target the `develop` branch for all Pull Requests.
